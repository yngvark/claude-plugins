# One-Shot stand-in preferences

These preferences guide decisions made on your behalf when you're in one-shot mode.
The decider subagent reads this file before answering each question. Edit freely.

## Dependencies
- Prefer libraries with many GitHub stars (>1k as a rough floor).
- Prefer actively-maintained projects (commits within last 6 months).
- Prefer well-documented libraries.

## Tradeoffs
- When in doubt, prefer simpler over more flexible.
- When in doubt, prefer existing repo conventions over introducing new patterns.
- When in doubt, prefer fewer dependencies.

## Testing
- Prefer tests that verify behavior, not implementation details.
